# Agent Resources - five starter task ideas

- Write the first hiring case: pick the work that keeps landing with no obvious owner, count the board rows that prove it, name the facet a new seat would fill and the reviewer independence it preserves - and recommend honestly, including "not yet, and here are the triggers that would change that"
- Run the onboarding research pass for the most recently opened seat in the company: its domain craft, the competitive reality, the market its department touches - a 3-source minimum per lane inside a 90-day recency window, findings landed in its card and playbook rather than a report nobody reads
- Sweep every seat card in the company for completeness: all six required H2s present, a live `## Seat memory` ledger on each, the review triangle intact in every department - report drift by file and line, and file each gap as its own board row
- Run the first improvement read on one seat, drawn only from its own record - what it produced, what its reviews said, what warnings trace back to it - ending in exactly one proposed amendment to its card or the playbook, with the evidence cited
- Build the first contractor roster: one file listing every human who currently does paid work for the company - name, role, rate, status - with `(not set yet)` wherever the founder has not supplied the fact
